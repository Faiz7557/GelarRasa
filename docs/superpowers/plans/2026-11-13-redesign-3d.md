# Redesign Visual, Siluet Indonesia, dan 3D — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TABAT memakai palet poster baru, menampilkan siluet Indonesia, dan punya tiga visual 3D informatif (menara pengulangan, tumpukan tahun, penampang gambut) tanpa dependensi baru.

**Architecture:** Token CSS diganti di `globals.css` (Tailwind v4 `@theme`), warna peta di `components/map/style.ts`. Pipeline menambah `indonesia.geojson`, `indonesia-inset.svg`, serta properti `t`/`y` di `blocks.geojson`. 3D peta memakai lapisan MapLibre `fill-extrusion` dengan `filter` berbasis properti (opasitas ekstrusi tidak mendukung feature-state, jadi sembunyi/tampil lewat filter); penampang gambut = SVG isometrik.

**Tech Stack:** Next.js 16, React 19, Tailwind 4, MapLibre GL 5, Recharts, Python 3.13 (geopandas/shapely).

**Spec:** `tabat-app/docs/07_REDESIGN_3D.md` (disetujui user 13 Nov 2026). Konteks app: `tabat-app/.claude/KONTEKS_APP.md`.

## Global Constraints

- Palet: Grow `#F0E6D3`, Hint of Caramel `#D4943A`, Potter's Clay `#A8432A`, Weathervane `#2C2318`; token lengkap persis 07 §4.2–§4.3.
- Caramel tidak pernah menjadi warna teks di atas latar terang; semua teks ≥ 4,5:1.
- Font: Bricolage Grotesque 800 (judul, `--font-display`), Inter 400/500 (isi, `--font-sans`), JetBrains Mono 500 (`--font-mono`) via `next/font/google`.
- Lencana DEMO dibedakan dengan garis putus-putus (`border-dashed`), bukan warna ungu.
- Tanpa dependensi npm baru.
- Legenda 3D wajib memuat: "1 lantai = 1 tahun berjejak 2015–2024, bukan peluang terbakar". Kata terlarang 04 §6 tetap berlaku (kalimat bernegasi ini sah).
- 3D: selalu ada tombol "Tampilan 2D"; `prefers-reduced-motion` → tanpa animasi kamera; WebGL mati → fallback 2D/daftar yang sudah ada.
- Berkas geo baru < 150 KB; `blocks.geojson` < 1,5 MB.
- `pipeline/check_numbers.py` tetap lulus; angka riset di layar tidak berubah (audit 0 selisih).
- Dev server paralel: `NEXT_DIST_DIR=.next/par/<id>`; jangan `npm run build` tanpa `NEXT_DIST_DIR`.
